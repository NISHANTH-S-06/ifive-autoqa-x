# Phase 4 AI Task Analyzer

## Overview

The AI Task Analyzer is an advanced, strictly local AI module built to evaluate developer tasks and formulate initial test plans deterministically. It serves as a foundation for future Large Language Model (LLM) integration without compromising data security or requiring third-party cloud services.

## Architecture

- **Provider Classification**: **DETERMINISTIC_HEURISTIC_PROVIDER**. The current `LocalAIProvider` does not make real HTTP requests to an LLM (such as Ollama) by default. Instead, it relies on static string-matching heuristics to deterministically output a standard scaffolded testing schema. This ensures zero risk of external data leakage or unstructured generation.
- **Schemas**: Validated with Pydantic (`AIAnalysisResponse`, `AIStepRecommendation`). Ensures the AI outputs strict JSON conforming to standard testing steps.
- **Service Integration**: `TaskAnalysisService` bridges the `ExternalTaskImport` records from the Mock Task Portal to the AI provider.
- **Frontend Integration**: An interactive `✨ AI Analyze` button surfaces the Risk Classification, Strategy, Missing Information, and Confidence Score directly into the `TaskImportsCore` UI.

## Security Constraints Enforced

1. **No Real Execution**: The AI *recommends* steps but cannot execute them.
2. **Local Only**: The provider is configured to use `localhost:11434` or fall back to an internal heuristics mock.
3. **Approval Gates**: Test plans generated by AI still require the human `Approve Plan` workflow before any execution can occur. Developers are also strictly prohibited from approving their own AI-generated tasks.

## Future Roadmap

- Provide deeper integration with Playwright auto-healing locators based on DOM structure.
- Feed previous failed test logs directly into the AI Analyzer for intelligent debugging suggestions.
