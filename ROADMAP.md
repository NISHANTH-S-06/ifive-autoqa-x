# Roadmap

## Milestone 1 - Scaffold

- Create project structure.
- Add baseline documentation and configuration.
- Add starter frontend, backend, and QA files.

## Milestone 2 - Website and Dashboard Shell

- Build Home, Products, Test Runs, Agents, Reports, and Settings pages.
- Add platform content from the website content plan.
- Add static dashboard preview data.

## Milestone 3 - Backend Foundation

- Add FastAPI app wiring.
- Add health, projects, test runs, results, reports, and agents routes.
- Add SQLite models and repositories.

## Milestone 4 - Playwright Pilot

- Add core fixtures and page objects.
- Add first ERP smoke tests.
- Enable HTML, trace, screenshot, video, console, and network evidence.

## Milestone 5 - Local AI Workflow

- Add Ollama prompt execution path.
- Generate test plans and candidate Playwright tests.
- Add human approval flow for generated and healed tests.

## Milestone 6 - Reporting and Safety Hardening

- Import Playwright results into the backend.
- Map failures to defects and owners.
- Add audit history and safety policy checks.
